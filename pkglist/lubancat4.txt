archlinuxarm-keyring

# Test kit for the bring-up this port claims. lubancat4-status reads these tools and
# prints one report; without them it still runs but skips the sections.
# Names checked against ALARM's own core.db/extra.db (versions in BOARD.md section 7).
#   linux-firmware-other  the ONLY firmware split this board can use today. panthor builds
#                   the path as "arm/mali/arch<MAJOR>.<MINOR>/mali_csffw.bin" from the GPU's
#                   own ID registers (panthor_fw.c:811), and the rk3588 gpu node is
#                   compatible = "rockchip,rk3588-mali", "arm,mali-valhall-csf", i.e. CSF, so
#                   it really is panthor. linux-firmware-other ships arch10.8/10.10/10.12 and
#                   on, which is what the module declares. 12 MiB download / 45 MiB installed.
#                   Do NOT use the linux-firmware meta package here: it pulls 16 splits,
#                   635 MiB download / 1.93 GiB installed, and every one of them except this
#                   is amdgpu/nvidia/intel/qcom/mellanox firmware this SoC has no device for.
#                   RGA3 and rkvdec need no firmware at all (grep finds no
#                   request_firmware/MODULE_FIRMWARE in those two drivers).
#   libdrm          modetest (modeset / connector / plane state)
#   libgpiod        gpiodetect, gpioinfo, gpiomon - the only sane way to see an XL9535
#   i2c-tools       i2cdetect, to check 0x21 on bus 6 and 0x5d on bus 5
#   v4l-utils       v4l2-ctl --list-devices, media-ctl -p for RGA / VPU / CIF
#   alsa-utils      aplay -l / arecord -l for the hdmi0-sound overlay
#   dtc             dtc and fdtoverlay on the board, to re-apply an overlay by hand
#   evtest          touch events from the panel's GT911
linux-firmware-other
libdrm
libgpiod
i2c-tools
v4l-utils
alsa-utils
dtc
evtest
